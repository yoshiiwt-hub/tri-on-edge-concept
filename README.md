## English

**Try on the Edge Now, KAIZEN the Future.**

Tri-On-Edge is an open concept and methodology for edge-based data processing in manufacturing.

This repository contains documentation describing the concepts, system architecture, data processing approach, development principles, and project management methodology of Tri-On-Edge.

The purpose of this repository is to make the ideas and knowledge of Tri-On-Edge openly available so that they can be studied, referenced, adapted, and improved.

---

### What is Tri-On-Edge?

Tri-On-Edge is a concept and implementation framework for connecting manufacturing sites and information systems through edge-based data processing.

Tri-On-Edge focuses on detecting meaningful changes in data generated by manufacturing processes and connecting those changes to subsequent processing, analysis, and improvement.

This concept was inspired by hands-on experience in software development and operation at the OT-IT boundary (the edge), and represents an independent conception by the author personally, containing no specific implementation or intellectual property belonging to any particular organization (source code, configuration data, internal documents, etc.).

The concept is built around three principles:

- **Trigger** — capturing what is happening at the manufacturing site
- **Trial** — verifying and challenging ideas through practical implementation
- **Trinity** — connecting people, technology, and expertise

Tri-On-Edge also defines four system domains:

- **Supervise** — monitoring, management, and common infrastructure
- **Stream** — real-time data processing
- **Stored** — stored data and analysis
- **Simulate** — virtual verification and simulation

### Tri-On-Edgeとは

Tri-On-Edgeは、エッジベースのデータ処理を通じて、製造現場と情報システムをつなぐためのコンセプト・実装フレームワークです。

Tri-On-Edgeは、製造プロセスから生成されるデータの中から意味のある変化を検知し、その変化を後続の処理・分析・改善につなげることに主眼を置いています。

本コンセプトは、OT-IT中間領域（エッジ）でのソフトウェア開発・運用に関する実務経験から着想を得たものであり、特定の実装や特定の組織の知的財産（ソースコード、設定データ、社内文書等）を含まない、著者個人による独立した考案である。

本コンセプトは、3つの原則を軸に構成されています。

- **Trigger** — 製造現場で起きていることを捉える
- **Trial** — 実践的な実装を通じてアイデアを検証し、試す
- **Trinity** — 人・技術・専門知識をつなぐ

また、Tri-On-Edgeは4つのシステム領域を定義しています。

- **Supervise** — 監視・管理・共通基盤
- **Stream** — リアルタイムデータ処理
- **Stored** — 蓄積データと分析
- **Simulate** — 仮想検証とシミュレーション
